## 1. 论文实验设计总览

这三组实验的共同目标是把论文主张从“能扫出 delay-energy Pareto frontier”提升为“preference-conditioned Pareto optimization under non-stationary edge contexts”。实验顺序建议如下:

| 实验 | 回答的问题 | 主要变量 | 关键指标 | 论文结论 |
|---|---|---|---|---|
| Unseen Preference Interpolation | 训练没见过的 `ω` 上是否仍然有效 | train/test preference split | unseen HV, interpolation gap, Spearman correlation | 模型学到连续偏好条件化策略, 不是记忆训练点 |
| Context Drift Recovery | 固定 `ω` 时环境变了能否恢复 | workload/channel/server context | recovery time, post-drift regret, rolling cost | buffer/feedback 帮助非平稳上下文恢复 |
| Joint Shift | `ω` 和环境同时变时是否仍然稳定 | preference + workload/channel/server 同时变化 | adaptation regret, tracking error, recovery time | 方法具备更强 test-time adaptation 能力 |

## 2. 实验一: Unseen Preference Interpolation

### 2.1 实验目的

证明 PC-FDN 在粗粒度 `ω` 上训练后, 可以在未见过的 preference vector `ω` 上插值生成有效解。这个实验直接支撑 “preference-conditioned” 的主线, 避免审稿人质疑模型只是为每个固定 `ω` 记忆一套策略。

### 2.2 偏好划分

训练只使用 5 个粗粒度偏好:

```python
train_omegas = [
    [0.00, 1.00],
    [0.25, 0.75],
    [0.50, 0.50],
    [0.75, 0.25],
    [1.00, 0.00],
]
```

测试使用 21 点 dense grid:

```python
eval_omega_T = np.linspace(0.0, 1.0, 21)
```

其中 seen set 是训练出现过的 5 个点, unseen set 是剩余 16 个点。论文主图用 21 点整体曲线, 表格单独报告 seen/unseen。

### 2.3 对比方法

```text
PC-FDN full: preference conditioning + omega buffer
PC-FDN w/o buffer: use_omega_buffer=False
PC-FDN w/o coarse-only setting: 21-point full-grid training, 作为性能上界参考
Discrete SAC / LDQN: 现有 baseline
Opt: per-step exhaustive oracle, 用于距离下界分析
```

### 2.4 指标

```text
Seen HV:
只在训练出现过的 5 个 ω 上计算 hypervolume。

Unseen HV:
只在未见过的 16 个 ω 上计算 hypervolume。

Interpolation gap:
gap = (HV_seen - HV_unseen) / max(HV_seen, 1e-8)
gap 越小, 表明插值越稳。

Spearman response:
ρ_delay = Spearman(ω_T, delay), 期望为负相关;
ρ_energy = Spearman(ω_T, energy), 期望为正相关。

Opt distance:
同一 eval grid 下, 计算每个 unseen 点到 Opt frontier 的最近欧氏距离或归一化 scalar regret。
```

### 2.5 图表

```text
Figure A1:
Pareto frontier with seen/unseen markers.
训练点用实心圆, unseen 测试点用空心圆。

Figure A2:
ω_T-delay 与 ω_T-energy response curves.
观察 unseen 点是否平滑落在 seen 点之间。

Table A1:
Seen HV, Unseen HV, Interpolation gap, ρ_delay, ρ_energy.
```

### 2.6 预期论文结论

PC-FDN 在只观察粗粒度 preference vector 的条件下, 仍能在 dense unseen preference grid 上产生平滑 Pareto frontier。若 unseen HV 与 seen HV 差距较小, 且 response curve 单调, 可以说明模型学习到了连续 preference-conditioned policy, 而不是离散偏好查表。

## 3. 实验二: Context Drift Recovery

### 3.1 实验目的

固定 `ω`, 只改变 workload/channel/server context, 检验 buffer/feedback 是否帮助策略从非平稳环境中恢复。这个实验把 buffer 模块从“加速训练的小技巧”提升为 “drift recovery” 机制。

### 3.2 固定偏好

主实验使用平衡偏好:

```python
omega = np.array([0.5, 0.5], dtype=np.float32)
```

补充实验可以加两个极端偏好:

```python
delay_oriented = np.array([0.8, 0.2], dtype=np.float32)
energy_oriented = np.array([0.2, 0.8], dtype=np.float32)
```

### 3.3 漂移类型

每类 drift 都分为 pre-drift context A 和 post-drift context B。

**Workload drift**

```python
context_A = dict(
    name="workload_random_moderate",
    num_tasks_max=32,
    task_mode="random",
    task_kwargs={},
)

context_B = dict(
    name="workload_poisson_burst",
    num_tasks_max=36,
    task_mode="poisson",
    task_kwargs=dict(lam0=20.0, lam1=8.0, period=40, size_mean=25.0),
)
```

**Channel drift**

```python
context_A = dict(
    name="channel_normal",
    fading_clip=(0.3, 2.5),
    tran_rate_scale=1.0,
)

context_B = dict(
    name="channel_weak",
    fading_clip=(0.1, 1.2),
    tran_rate_scale=0.7,
)
```

**Server context drift**

```python
context_A = dict(
    name="server_normal",
    server_keep_ratio=1.0,
    f_scale=1.0,
)

context_B = dict(
    name="server_degraded",
    server_keep_ratio=0.67,  # Emax=6 时保留约 4 台
    f_scale=0.75,
)
```

### 3.4 实验流程

```text
1. 在 context A 上训练或加载已训练 PC-FDN。
2. 用固定 ω 在 context A 上运行 pre-drift episodes, 建立稳定表现与 buffer entries。
3. 在 episode index = t_shift 处切换到 context B。
4. 继续运行 post-drift episodes, 允许 full 方法使用 buffer retrieve + online buffer update。
5. 记录每个 episode 的 delay, energy, scalar cost, buffer hit rate, gate rate。
```

建议:

```text
n_pre_episodes = 20
n_post_episodes = 40
t_shift = 20
eval_seeds = [0, 1, 2]  # 时间不够时先跑 [0]
```

### 3.5 对比方法

```text
PC-FDN full:
使用 omega buffer 初始化 prior, post-drift 后继续 online update buffer。

PC-FDN frozen buffer:
使用 drift 前 buffer 初始化, 但 post-drift 不更新 buffer。

PC-FDN w/o buffer:
不使用 omega buffer, 只依赖 actor 当前策略。

PC-FDN w/o context key:
buffer key 只用 omega, 不用 env_ctx; 用于证明 context-aware key 有必要。

Discrete SAC / LDQN:
作为无显式 preference memory 的 baseline。
```

### 3.6 指标

```text
Rolling scalar cost:
J_ω = ω_T * delay + ω_E * energy

Post-drift regret:
regret_t = J_method,t - J_opt,t

Recovery time:
post-drift rolling cost 首次回到 post-drift 稳态均值的 1.1 倍以内所需 episode 数。

Final post-drift cost:
post-drift 最后 10 个 episode 的平均 J_ω。

Buffer diagnostics:
hit_rate, gate_rate, mean_nn_dist, mean_conf。
```

### 3.7 图表

```text
Figure B1:
Workload drift recovery curve: rolling J_ω with std band.

Figure B2:
Channel drift recovery curve: rolling J_ω with std band.

Figure B3:
Server drift recovery curve: rolling J_ω with std band.

Table B1:
各 drift 类型下的 recovery time, post-drift regret, final cost。
```

### 3.8 预期论文结论

当 workload、channel 或 server context 发生变化时, full PC-FDN 的 post-drift cost 下降更快, recovery time 更短。若 frozen buffer 比 w/o buffer 好但弱于 full, 可以进一步说明 online feedback update 对 drift recovery 有贡献。

## 4. 实验三: Joint Shift

### 4.1 实验目的

同时改变 `ω` 和 workload/context, 评估最强非平稳场景。这个实验是前两个实验的组合压力测试, 用于强化论文的 test-time adaptation 叙事。

### 4.2 Sudden Joint Shift 设置

```python
phase_A = dict(
    name="energy_light",
    omega=np.array([0.2, 0.8], dtype=np.float32),
    num_tasks_max=32,
    task_mode="random",
    task_kwargs={},
    fading_clip=(0.3, 2.5),
    tran_rate_scale=1.0,
    f_scale=1.0,
)

phase_B = dict(
    name="delay_burst_weak_channel",
    omega=np.array([0.8, 0.2], dtype=np.float32),
    num_tasks_max=36,
    task_mode="poisson",
    task_kwargs=dict(lam0=20.0, lam1=8.0, period=40, size_mean=25.0),
    fading_clip=(0.1, 1.2),
    tran_rate_scale=0.7,
    f_scale=0.9,
)
```

流程:

```text
episodes 0-19: phase_A
episodes 20-59: phase_B
```

### 4.3 Gradual Joint Shift 设置

```python
for i in range(n_episodes):
    s = min(max((i - 10) / 30.0, 0.0), 1.0)
    omega_T = 0.2 + 0.6 * s
    lam0 = 12.0 + 10.0 * s
    tran_rate_scale = 1.0 - 0.3 * s
```

含义:

```text
ω 从 energy-oriented 平滑过渡到 delay-oriented。
workload 从 moderate 平滑过渡到 burst。
channel 从 normal 平滑过渡到 weak。
```

### 4.4 对比方法

```text
PC-FDN full
PC-FDN w/o omega buffer
PC-FDN w/o context key in buffer
PC-FDN w/o preference conditioning
Discrete SAC / LDQN
```

### 4.5 指标

```text
Rolling J_ω:
每个 episode 用当前 episode 的 ω 计算 scalar cost。

Adaptation regret:
post-shift 区间内 sum(J_method - J_opt)。

Preference tracking error:
当 ω_T 上升时, delay 应下降或保持低位; energy 可上升。
可用 sign agreement 统计:
sign(Δω_T) 与 sign(-Δdelay) 是否一致。

Recovery time:
sudden joint shift 后回到 phase_B 稳态 1.1 倍以内所需 episode 数。

Buffer diagnostics:
hit_rate, gate_rate, mean_nn_dist, mean_conf 随 episode 的变化。
```

### 4.6 图表

```text

Figure C2:
Gradual joint shift: delay 和 energy 随 episode 的变化。

Figure C3:
Buffer hit rate / gate rate 与 J_ω recovery 的对应关系。

Table C1:
Sudden/gradual joint shift 下的 adaptation regret, recovery time, final cost。
```

### 4.7 预期论文结论

PC-FDN 在 preference vector 和 workload/channel context 同时变化时仍能调整卸载策略。若 full 方法在 sudden 与 gradual shift 下均优于 w/o buffer 和 w/o context key, 可以说明 context-aware feedback memory 是 test-time adaptation 的关键。

```python
def apply_context_profile(env, rng, profile):
    old_clip = (env.fading_lo, env.fading_hi)
    if "fading_clip" in profile:
        env.fading_lo, env.fading_hi = profile["fading_clip"]

    E, f_E, tran_rate, _ = env.sample_context(rng)

    if "server_keep_ratio" in profile:
        keep = max(1, int(round(E * float(profile["server_keep_ratio"]))))
        E = keep
        f_E[keep:] = 0.0
        tran_rate[keep:] = 0.0

    if "f_scale" in profile:
        f_E[:E] = f_E[:E] * float(profile["f_scale"])

    if "tran_rate_scale" in profile:
        tran_rate[:E] = tran_rate[:E] * float(profile["tran_rate_scale"])

    return E, f_E, tran_rate, old_clip
```

```python
def scalar_cost(delay, energy, omega, alpha_T=1.0, alpha_E=1.0):
    return float(omega[0]) * float(alpha_T) * float(delay) + \
           float(omega[1]) * float(alpha_E) * float(energy)


def recovery_time(costs, shift_idx, tail_window=10, tol_factor=1.1):
    costs = np.asarray(costs, dtype=np.float64)
    post = costs[shift_idx:]
    if len(post) <= tail_window:
        return np.nan
    target = np.mean(post[-tail_window:]) * tol_factor
    for i in range(shift_idx, len(costs)):
        if costs[i] <= target:
            return float(i - shift_idx)
    return float(len(costs) - shift_idx)
```

```python
                                   alpha_T=1.0, alpha_E=1.0,
                                   stochastic=False)

    if online_update and omega_buf is not None:
        score = -scalar_cost(delay, energy, omega, 1.0, 1.0)
        omega_buf.update(omega, latent, env_ctx=env_ctx,
                         reward=score, current_epoch=epi)

    env.fading_lo, env.fading_hi = old_clip
```

## 6. 论文写法建议

这三组实验在论文中建议放在主 Pareto 对比之后, 作为 “Generalization and Adaptation Analysis” 小节。

段落顺序:

```text
First, we evaluate whether PC-FDN interpolates to unseen preference vectors.
Second, we fix the preference vector and change edge contexts to measure drift recovery.
Finally, we jointly shift preference and workload to stress-test test-time adaptation.
```

中文含义:

```text
先证明能泛化到没见过的 ω;
再证明环境变了能恢复;
最后证明 ω 和环境一起变也能调整。
```

写作时避免把 buffer 说成简单缓存。更好的表述是:

```text
context-aware feedback memory
```

或:

```text
preference-conditioned feedback memory
```

如果实验结果符合预期, 论文核心结论可以写为:

```text
PC-FDN learns a continuous preference-conditioned policy and maintains stable Pareto allocation under non-stationary edge contexts, while the feedback memory accelerates recovery after preference and context shifts.
```
