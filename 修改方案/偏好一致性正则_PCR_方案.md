# 偏好一致性正则（PCR）—— 创新点方案（供 Review）

> 目标：在**现有双目标（delay-energy）偏好条件化卸载系统**上，新增一个**真实、被多目标设定驱动、可消融验证**的机制 PCR，作为本文的核心方法贡献。
> 本文档自包含：先交代现有系统与"已被否定的组件"，再给 PCR 的问题动机、形式化定义、实现、消融设计、诚实定位、风险，最后列出**请 reviewer 回答的问题**。

---

## 0. 背景与现有系统（reviewer 必读）

**现有系统 FDEdge / MOFD-V5**：多目标、偏好条件化的边缘计算卸载强化学习。

- **任务**：每个时隙到达若干任务，决定每个任务卸载到哪台边缘服务器（Emax 台）。
- **目标**：2 个 —— 延迟 delay、能耗 energy（`r_vec=(-delay, -energy)`）。
- **偏好**：用户给 `ω=(ω_T, ω_E)`，`ω_T+ω_E=1`。**ω 作为状态的一部分**喂给策略。
- **单策略覆盖偏好谱**：一个策略 `π(a|s,ω)` 对所有 ω 给分配；评估时**扫 ω 得 Pareto 前沿**。
- **方法构件（均为现有/借用技术，将在论文中引用）**：
  - actor = **反馈扩散策略**（DDPM 多步去噪，去噪起点 = 上一步动作概率，即"反馈"）；**该骨干源自已发表的 delay-only 反馈扩散卸载工作，本文作为 backbone 引用，不主张为创新**；
  - critic = **向量 Q** `Q(s,a)=(Q_T,Q_E)∈R^2`（逐目标返回，`Q_*` 越大代表对应 cost 越低）；
  - ω 加权 critic loss、COR（目标冲突正则，COLA 风格）、PopArt-lite（逐目标量级归一）、SAC 自动温度 α。
- **现状**：已跑通，PC-FDN 的 HV 优于 LDQN / DiscreteSAC 基线。

**已被否定/移除的组件（诚实交代，避免 reviewer 误解方法栈）**：
- **ω-buffer / 偏好漂移**：经多轮诊断为循环论证，已否决；
- **H-MCSS（三源候选 + Critic 选优）**：消融实测显示**净负**（完整三源 HV 最低，单源 feedback 反而 +14.8%），已不作为卖点。

**因此本文的方法贡献需要一个新的、有实证的机制 —— 即 PCR。**

---

## 1. PCR 要解决的真实问题

**单策略 + 标量化 MORL 不保证"偏好单调"。** 理论上 `ω_E` 增大（更重视能耗）应使实际能耗单调下降、延迟单调上升；但 ω-条件化单策略训练出来的 Pareto 前沿常常**抖动 / 自交叉 / 反向**（ω_E 增大能耗反升）。

- 该问题在 **delay-only 卸载论文中不存在**（无 ω），是多目标偏好谱设定特有的。
- 现有系统**只能靠标量化奖励隐式学**偏好一致性，**没有任何显式机制保证它** → 前沿质量不稳。
- 本项目已有的验收指标正是冲它去的：
  - `Spearman ρ(ω_E, energy)` 应 ≤ −0.70；`ρ(ω_E, delay)` 应 ≥ +0.70。
  - 历史 broken 状态下两者绝对值估计 < 0.3，即偏好基本没被遵守。

**PCR = 把"偏好单调"从"祈祷它发生"变成"显式约束它发生"。**

---

## 2. PCR 形式化定义

定义在状态 s、偏好 ω 下，策略的**期望逐目标价值**（用向量 critic）：
```
V_E(s,ω) = Σ_a π(a|s,ω) · Q_E(s,a)      # 能耗通道期望 (越大=能耗越低)
V_T(s,ω) = Σ_a π(a|s,ω) · Q_T(s,a)      # 延迟通道期望 (越大=延迟越低)
```

**偏好单调性目标**：若 `ω_E^a > ω_E^b`（a 更偏能耗），则
```
V_E(s,ω_a) ≥ V_E(s,ω_b)   （a 应取更省能耗的动作）
V_T(s,ω_a) ≤ V_T(s,ω_b)   （a 应接受更高延迟）
```

**PCR 惩罚（铰链 hinge）**：每个训练步采一对偏好 `ω_a,ω_b`（约束 `ω_E^a>ω_E^b`），对一个 batch 的状态 s（用 `_relabel_state_omega` 把 ω 槽替换为 ω_a/ω_b）：
```
L_PCR = mean_s [ relu( V_E(s,ω_b) − V_E(s,ω_a) )      # 能耗序违反
              +  relu( V_T(s,ω_a) − V_T(s,ω_b) ) ]    # 延迟序违反
```
**总损失**：`actor_loss += λ_PCR · L_PCR`。

- Q 通道在 PCR 中 **detach**（不反传到 critic），梯度只塑形 **actor**——因为实际前沿由 actor 选动作决定。
- **可选 margin 版**（更强但多一个超参）：要求分离量随偏好差成比例
  `relu( m·(ω_E^a−ω_E^b) − (V_E(s,ω_a)−V_E(s,ω_b)) ) + 对称延迟项`。第一版建议用无 margin 的纯序约束。

**实现量**：复用现有 `_relabel_state_omega`（COR 已用）、向量 Q、`_scalarize_q`，约几十行；开关 `use_pcr` + 系数 `pcr_lambda`。

---

## 3. 训练与评估

- 训练：在 `update()` 的 actor 更新里加 `λ_PCR·L_PCR`；每步采 1~K 对偏好（K 大降方差）。
- 建议：critic warmup 若干 epoch 后再开 PCR（避免早期 Q 不准时强加错误序）。
- 评估：扫 ω 21 点得前沿，照常算 HV / 前沿点。

---

## 4. 消融设计（用现成指标，直接证明有没有用）

开关 `use_pcr ∈ {False, True}`，各 **≥3 seeds**，对比：

| 指标 | 含义 | 期望方向 |
|---|---|---|
| Spearman ρ(ω_E, energy) | 偏好-能耗一致性 | 更负（趋近 −1）|
| Spearman ρ(ω_E, delay) | 偏好-延迟一致性 | 更正 |
| 单调违反率 | 相邻 ω 对中违反序的比例 | 下降 |
| HV | 前沿整体质量 | 持平或上升 |
| 能耗 spread/均值 | 前沿铺开程度 | 上升 |
| #非支配点 | 有效前沿点数 | 持平或上升 |

外加 `λ_PCR` 敏感性曲线。**判据**：PCR 显著提升 ρ 与降低违反率、且 HV 不降（最好升）→ 成立；若 HV 明显下降或指标无变化 → **如实不写**（符合"实验必须真"红线）。

## 6. 已识别风险

| # | 风险 | 对策 |
|---|---|---|
| R1 | 强加单调可能**收缩前沿、压低 HV** | 监控 HV；调 λ_PCR；用敏感性曲线找拐点 |
| R2 | PCR 依赖 critic 准确（Q_E/Q_T 有意义），早期 Q 不准会强加**错误序** | critic warmup 后再开；或改用 MC 实际 cost 替代 Q |
| R3 | 每步单对 ω 方差大 | 每步采 K 对、或大 batch |
| R4 | 若策略本就近单调 → PCR 近 no-op | 如实报告无效，不硬写 |
| R5 | novelty 仍属机制级增量，reviewer 或评"已知思路" | 靠"特定设定 + 强实证增益 + 部署可预测性需求"强化；投应用类 venue |
